# Online Exam App

A web-based Online Examination System built using React.js and Firebase.

## Features

- Student Registration & Login
- Admin Login
- Online MCQ Examination
- Exam Timer
- Automatic Score Calculation
- Firebase Firestore Database Integration
- Admin Dashboard for Result Management

## Technologies Used

- React.js
- Firebase Authentication
- Firestore Database
- JavaScript
- CSS
